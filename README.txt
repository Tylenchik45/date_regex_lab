Вариант: Проверка и поиск синтаксически корректных дат в формате ДД.ММ.ГГГГ

## Требования:
- Python 3.12 или выше (на нем написан проект) (проверить версию: 'python --version')
- Git (для клонирования репозитория)
- re, unitest, requests, typing

## Регулярное выражение:
Допускается строго: ДД.ММ.ГГГГ

Месяцы с 31 днём: 01, 03, 05, 07, 08, 10, 12
Месяцы с 30 днями: 04, 06, 09, 11
Февраль: 02

Год високосный, если год делится на 4 и либо не делится на 100, либо делится на 400

РВ для високосного года:
(?:
    [0-9]{2}(?:0[48]|[2468][048]|[13579][26])
  |
    (?:[02468][048]|[13579][26])00
)
Первая часть ловит годы, которые делятся на 4, но не на 100.
Вторая часть ловит годы, которые делятся на 400.

 Основное ядро даты
(?:
    (?:0[1-9]|[12][0-9]|3[01])\.(?:0[13578]|1[02])\.[0-9]{4}
  |
    (?:0[1-9]|[12][0-9]|30)\.(?:0[469]|11)\.[0-9]{4}
  |
    (?:0[1-9]|1[0-9]|2[0-8])\.02\.[0-9]{4}
  |
    29\.02\.
    (?:
        [0-9]{2}(?:0[48]|[2468][048]|[13579][26])
      |
        (?:[02468][048]|[13579][26])00
    )
)


## Для запуска проекта:

>git clone https://github.com/Tylenchik45/date_regex_lab.git
>cd date_regex_lab
>python src\main.py
////////////////////

## Запуск через PyCharm:
1. Откройте PyCharm -> File -> Open _> выберите папку проекта.
3. Откройте папку src -> файл 'main.py'.
4. Нажмите -> Run 'main' (или 'Shift + F10').
5. Результат работы будет выведен в консоль PyCharm.

## Запуск тестов через PyCharm:
1. Откройте PyCharm -> File -> Open _> выберите папку проекта.
2. ПКМ по папке tests -> 'Run python tests in test...'
3. Результат работы будет выведен в консоль PyCharm.
